# Forecasting Religious Tourism
## Machine Learning Analysis of Pilgrimage Patterns to Sacred Sites in Nepal

### Project Structure
```
thesis_project/
├── data/                          
│   ├── pilgrimage_data_raw.csv    ← Raw messy data (input)
│   └── pilgrimage_data_clean.csv  ← Cleaned data (generated by notebook 01)
├── notebooks/                     
│   ├── 01_data_cleaning.ipynb     ← Load, clean, save
│   ├── 02_eda.ipynb               ← Visualise and explore
│   ├── 03_time_series.ipynb       ← ARIMA and SARIMA
│   ├── 04_ml_models.ipynb         ← Random Forest and XGBoost
│   └── 05_evaluation.ipynb        ← Compare all models
├── models/                        ← Saved trained models (.pkl)
├── app.py                         ← Streamlit dashboard
├── requirements.txt               ← Python dependencies
└── README.md                      ← This file
```

### How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run notebooks in order: 01 → 02 → 03 → 04 → 05
3. Launch dashboard: `streamlit run app.py`
